# DevCamp 2.0 — Spotify Website Clone

A student-made static Spotify-inspired website using HTML and CSS only.

## Files
- `index.html` — Home page
- `browse.html` — Browse genres
- `playlist.html` — Playlist details and track table
- `signup.html` — Optional signup form practice
- `style.css` — Shared external stylesheet

## Run locally
1. Extract this ZIP.
2. Open the `DevCamp_Spotify_Clone` folder.
3. Double-click `index.html` to open it in a browser.

Internet is needed for the remote Unsplash images and Google Fonts. The layout and CSS still work without them.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, e.g. `devcamp-spotify-clone`.
2. Upload all five website files (`index.html`, `browse.html`, `playlist.html`, `signup.html`, `style.css`) to the repository's root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Copy the URL shown in Settings → Pages.

## Before submitting
- Open every page and test the navigation links.
- Test the layout on a narrow/mobile screen.
- Confirm the repository is public and the live URL works.
- Submit both the GitHub repository URL and the live deployed URL.

This is an educational mockup, not the official Spotify website. The signup form does not create or store accounts, and the Play button does not play audio.
